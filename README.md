# voice-recorder-design
Учебный проект по предмету "Архитектура программных систем": проектирование ПО диктофона

Этот репозиторий содержит результаты учебного проекта по проектированию программного обеспечения для встроенного процессора диктофона.

## Задача проекта
Разработать программное обеспечение (и внешний вид) для цифрового диктофона. 
Основные функции: запись до 100 сообщений, воспроизведение, удаление, сортировка, работа с внешней и внутренней памятью, режим энергосбережения.


3. В работе:
   - Построение диаграмм последовательности (Sequence Diagrams).
   - Подготовка итоговой технической документации.
